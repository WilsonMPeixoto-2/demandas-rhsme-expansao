# Refinamento web inspirado nas diretrizes Apple

Esta skill é uma **adaptação original para interfaces web** e não é uma skill oficial da Apple. Consultar sempre as [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) e [recursos de design](https://developer.apple.com/design/resources/) para esclarecer recomendações atuais; não transformar exemplos de iOS, macOS ou SwiftUI em regras obrigatórias para aplicações React.

## Princípios aplicáveis ao projeto
1. Priorizar conteúdo e decisões operacionais: a navegação existe para orientar o usuário, não para exibir efeitos.
2. Usar profundidade, contraste e transparência apenas quando tornam a hierarquia mais clara. Verificar legibilidade real sobre imagem de fundo.
3. Materiais como Liquid Glass são referências de comportamento visual, não instruções para replicação indiscriminada ou uso de bibliotecas proprietárias.
4. Construir iconografia com mesma família geométrica, peso óptico e estados; não incluir SF Symbols proprietários no site sem verificar a licença e os direitos de uso.
5. Preservar acessibilidade web: nomes acessíveis, foco visível, tecla Tab/Escape, reflow, contraste e respeito a `prefers-reduced-motion`.
6. Atribuir movimento a mudanças significativas de contexto; evitar animações decorativas competitivas com o trabalho.
7. Não alterar a identidade municipal, os quatro destinos, a imagem aprovada dos Arcos da Lapa nem marca Fluxo CTRH em nome da estética Apple.

## Entrega
Uma revisão visual é válida somente se demonstrar telas reais e comparar antes/depois, com limitações explicitadas. Aprovação artística do responsável precede qualquer aplicação ao código operacional. Consulte `AGENTS.md` e a skill `cthr-sidebar-visual-quality` para precedência e escopo.
